# SunuSchool

Prototype structuré HTML, CSS et JavaScript. Ouvrez `index.html` dans un navigateur.

## Démo
- Admin : `ADM-001` / `admin123`
- Enseignant : `ENS-2025-001` / `TEMP1234`
- Élève : `SN-2025-0412` / `ELEVE123`

Les données sont enregistrées localement dans le navigateur. Cette version est une base front-end : la sécurité réelle, les SMS/WhatsApp et les paiements réels nécessitent Supabase ou un backend.
